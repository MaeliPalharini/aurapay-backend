# AuraPay Backend

## Sobre o projeto
O AuraPay é um projeto acadêmico desenvolvido para a disciplina de Projeto de Software, com o objetivo de simular uma plataforma de carteira digital.

A proposta do sistema é permitir operações financeiras básicas, começando pelo cadastro de clientes e criação de carteiras digitais, com evolução incremental ao longo das entregas da disciplina.

## Objetivo
Praticar o desenvolvimento de uma aplicação backend utilizando tecnologias e padrões de mercado, com foco em organização, arquitetura e evolução por funcionalidades.

## Tecnologias
- Java 21
- Spring Boot
- PostgreSQL
- Maven
- Arquitetura Hexagonal

## Escopo inicial
Na primeira entrega (AC1), o projeto terá como funcionalidade principal:

- cadastro de cliente
- criação de carteira digital vinculada ao cliente

## Próximas evoluções previstas
Ao longo das próximas entregas, o sistema poderá evoluir com funcionalidades como:

- depósito em carteira
- consulta de saldo
- transferência entre carteiras
- bloqueio de carteira

## Estrutura do projeto
O backend está sendo organizado com base em arquitetura hexagonal, separando responsabilidades entre domínio, aplicação, adaptadores e configuração.

## Status
Projeto em desenvolvimento inicial.
